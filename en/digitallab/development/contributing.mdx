DigitalLab welcomes community participation. You can submit improvements through Issues or Pull Requests.

## Feedback and reporting channels

| Channel | Address / contact |
| --- | --- |
| GitHub Issues | [https://github.com/ZWWF0906/Digital-Lab/issues](https://github.com/ZWWF0906/Digital-Lab/issues) |
| Email | [ZWWF0906@outlook.com](mailto:ZWWF0906@outlook.com) |

When submitting an issue, please describe the following information as much as possible:

- Operating system version
- DigitalLab version number
- Reproduction steps
- Expected behavior and actual behavior
- If there is an exception, attach relevant excerpts from `%APPDATA%\digital-lab\digital-lab.log`

## Pull Request

If you want to submit code changes, please fork the repository and make modifications on your branch, then submit them through a Pull Request. Before submitting, ensure your changes run correctly in the local development environment.

## Multilingual documentation

The repository already contains user-facing documentation in multiple languages:

- `README.md` / `README.en-US.md` / `README.ja-JP.md`
- `CHANGELOG.zh-CN.md` / `CHANGELOG.md` / `CHANGELOG.ja-JP.md`
- `PRIVACY.md` (contains Simplified Chinese, English, and Japanese versions)

If your changes affect user-visible copy or documentation, consider whether other language versions also need to be updated to keep information consistent.

<Note>
  This document does not specify coding standards, branch strategy, CLA, or CI workflow. Please follow the existing code style in the repository, and communicate with the maintainers through Issues when necessary.
</Note>
