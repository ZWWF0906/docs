DigitalLab's feature evolution is divided into completed milestones and planned directions that have not yet been released. The first two sections are derived from the Roadmap chapter in the repository README, with no additional commitments or timelines added.

## Completed milestones

| Milestone | Version |
| --- | --- |
| Realtime system monitoring | v1.0.0 |
| Hardware information center | v1.0.0 |
| NAS SSH management | v1.0.0 |
| AI Assistant | v1.0.0 |
| Electron + Python architecture | v1.0.0 |
| Light theme and theme switching | v1.1.0 |
| Feedback and report entry point | v1.1.0 |
| Personal Digital Memory | v1.6.0 |

## Planned directions

<Warning>
  The following items have not yet been released, and no release date is given in the source documentation. They reflect current product direction only and do not constitute a feature commitment.
</Warning>

- Agent automation capabilities
- Plugin system
- Support for more NAS platforms
- Data analysis and timeline system

The README Roadmap does not separately list the following capabilities; they are compiled from user-visible additions in the changelog.

| Capability | Initial version | Description |

| AI local memory | v1.2.0 | Optional feature, off by default |

| AI memory structuring | v1.5.0 | Entries now carry id, tag and source fields |

| Local memory retrieval | v1.6.0 | Pure local keyword + structured metadata relevance ranking (phase one, no vector library introduced) |
