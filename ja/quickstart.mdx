本ガイドでは、DigitalLab のインストールから初回利用までの全工程をご案内します。GitHub の `main` ブランチにある v1.6.0 の実際の機能に基づいて記載しています。

## 準備

開始する前に、お使いの PC が [システム要件](/ja/digitallab/getting-started/system-requirements) を満たしていることを確認し、[インストールガイド](/ja/digitallab/getting-started/installation) に従って DigitalLab をインストールしてください。v1.6.1 以降の正式版は Microsoft Store でインストールおよびアップデートされ、v1.6.0 は GitHub 単体インストーラーを提供する最後のバージョンです。

## 初回起動

<Steps>
  <Step title="起動とスプラッシュアニメーション">
    初回起動時、アプリはスプラッシュアニメーションを再生します。六角形と波形のストローク、ロゴマークの出現、自己診断項目が順次点灯します。**設定パネル**の**ソフトウェア**ページでこのアニメーションをオフにでき、オフにすると次回起動時からメイン画面に直接入ります。
  </Step>
  <Step title="表示言語を選択">
    スプラッシュアニメーション終了後、ガイドの最初のステップとなる**表示言語の選択**画面が表示されます。DigitalLab は簡体字中国語、英語、日本語に対応しています。選択後すぐに有効になり、後から**設定パネル**でいつでも変更できます。
  </Step>
  <Step title="NAS デバイスを追加">
    2 番目のステップは**NAS デバイスを 1 台追加**することです。以下の情報を入力してください。

    - **名前**: デバイス名
    - **ホスト**: NAS の IP アドレス
    - **ポート**: SSH ポート（通常は 22）
    - **ユーザー名**: SSH ユーザー名
    - **パスワード**: SSH パスワード

    保存後、アプリは接続を試みます。パスワードは Windows DPAPI 暗号化でローカルに保存されます。「後で設定」または「NAS はありません — ローカル監視を使用」をクリックしてこのステップをスキップすることもできます。
  </Step>
  <Step title="接続を確認">
    3 番目のステップは**接続の確認**です。アプリは NAS の SSH 接続性をテストします。接続に成功しデバイスがオンラインであればガイドは完了します。タイムアウトまたは失敗した場合は、再試行またはスキップを選択でき、後から**設定パネル**で再テストできます。

    NAS を初めて接続する際、その SSH ホストフィンガープリントを確認して信頼する必要があります。信頼されていないホストには認証情報が送信されません。接続確認でホストが未信頼と表示された場合は、**設定パネル**の **NAS デバイス**ページでフィンガープリントを確認し、「確認しました。このホストを信頼する」をクリックしてください。詳細は [NAS と SSH ターミナル](/ja/digitallab/user-guide/nas-ssh-terminal) を参照してください。
  </Step>
</Steps>

## 日常利用

### ダッシュボードを確認

ガイド完了後、メイン画面にはデフォルトで [ダッシュボード](/ja/digitallab/user-guide/dashboard) が表示されます。ここでは以下を確認できます。

- CPU、メモリ、ディスク、ネットワークのリアルタイム監視指標
- 24 時間のパフォーマンス履歴グラフ
- プロセス Top 15 リスト
- 設定済み NAS デバイスのステータスカード

### デバイスセンターを開く

サイドバーの**デバイスセンター**をクリックすると、ローカルマシンのハードウェア全体像が表示されます。

- CPU モデル、コア数、スレッド数、周波数
- メモリ容量、タイプ、周波数
- GPU モデル、VRAM、温度
- ディスクモデル、容量、健全性
- ディスプレイ、ネットワークアダプター、システム情報

### AI アシスタントを使用

<Warning>
  AI アシスタントは現在**テスト段階**です。初回入室時にポップアップが表示されます。現在は会話モードで、Agent のツール呼び出し機能は含まれていません。
</Warning>

AI アシスタントを利用するには、まず**設定パネル**の **AI 設定**ページで、以下のいずれかの設定を行ってください。

- **Ollama ローカル**: ローカルの Ollama アドレス（デフォルト `http://localhost:11434`）とモデル名（例: `qwen2.5:7b-instruct-q4_K_M`）を入力
- **クラウド API**: OpenAI 互換 API のアドレス、API Key、モデル名（例: DeepSeek）を入力。リモートエンドポイントは `https` を使用する必要があります。ローカルのループバックアドレスは `http` を使用できます

AI プロバイダー、サービスアドレス、API Key などの機密設定を変更する際、アプリはシステム標準の確認ダイアログを表示します。設定完了後、AI アシスタントパネルに戻って会話を開始できます。AI は現在のシステム状態をコンテキストとして自動的に注入し、CPU、メモリ、ディスク、ハードウェア、NAS に関する質問への回答を支援します。

<Info>
  クラウドモデルを使用する場合、会話内容とシステム状態のサマリーが、設定したサーバーエンドポイントにリクエストとともに送信されます。AI データフローの詳細については [AI データフロー](/ja/digitallab/privacy/ai-data-flow) を参照してください。
</Info>

### SSH ターミナルに接続

<Warning>
  SSH ターミナルは現在**テスト段階**です。初回入室時にポップアップが表示されます。SSH セッションは自動再接続に対応していません。
</Warning>

SSH ターミナルを使用する前に、NAS デバイスで SSH サービスが有効になっていること、**設定パネル**で認証情報が正しく設定されていること、およびホストフィンガープリントが信頼されていることを確認してください。サイドバーの**ターミナル**をクリックすると、パネルにオンラインの NAS デバイスが一覧表示されます。デバイス項目のボタンをクリックし、システムの「打开 SSH 终端？」（SSH ターミナルを開きますか？。v1.6.0 ではこのダイアログは中国語で表示されます）ダイアログで確認すると、ターミナルは独立した「DigitalLab Terminal」ウィンドウで起動します。このウィンドウを閉じると SSH セッションは終了し、必要に応じてターミナルパネルから再開してください。
