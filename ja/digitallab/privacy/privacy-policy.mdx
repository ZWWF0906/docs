DigitalLab は基本的にローカル環境で動作します。ハードウェアとパフォーマンスのデータは端末上で収集・表示・保存され、監視データ、設定、AI データは既定で端末上にのみ書き込まれます。

## 基本原則

アプリにはテレメトリー、ユーザー行動の追跡、バックグラウンド送信機能はありません。

データが端末外へ出るのは次の 3 つの場合を区別する必要があります。

1. **ローカルの Ollama モデル**：既定アドレスは本機の `http://localhost:11434` であり、リクエストは端末外へ出ません。Ollama のアドレスを他のホストに変更した場合、リクエストは当該ホストへ送信され、以下の [AI エンドポイントの通信ポリシー](#ai-エンドポイントの通信ポリシー) が適用されます。
2. **クラウド AI モデル（OpenAI 互換 API、例：DeepSeek）**：ユーザーが AI アシスタント機能を使用した場合に限り、今回のリクエスト内容が設定したサービスエンドポイントへ送信され、当該サービス提供者が処理し、そのプライバシーポリシーに従います。
3. **NAS デバイス**：ユーザーが NAS を設定した場合に限り、アプリは入力したホストアドレスとポートへ SSH 接続して監視データの収集とターミナルセッションを行います。アプリは接続先をローカルネットワーク内に限定しません。データが経由するネットワークパスは入力したアドレスとユーザーのネットワーク環境（例：ローカルネットワーク、VPN、Tailscale）に依存します。収集された NAS の監視データは端末上に保存されます。

上記以外の状況では、アプリが能動的に遠隔サーバーへデータを送信することはありません。また：

- **認証情報**：API Key、NAS パスワードなどの認証情報の値は Windows DPAPI の現在のユーザー範囲で暗号化して保存します。詳細は [機密情報の取り扱い](/ja/digitallab/privacy/sensitive-information) を参照してください。
- **転送**：リモート AI エンドポイントは HTTPS を使用し、既定の証明書検証を維持する必要があります。HTTP は loopback アドレスと、IP とポートで正確に許可したプライベートネットワークまたは Tailscale アドレスのみ許可されます。
- **ログ**：ログには AI の対話内容とリクエストコンテキストは含まれません。ログシステム自体は汎用的なフィールドマスキングを行いません。AI リクエストが失敗した場合、画面に表示されるエラー概要は限定的にマスキングされます（URL を除去し、認証情報類のキーと値を置換）。これは画面のエラー表示の処理であり、ログのマスキングではなく、ログの内容がマスキングされたことを示すものではありません。詳細は [データ処理と保存](/ja/digitallab/privacy/data-storage#ログ) を参照してください。

## 収集する情報

DigitalLab は以下の情報を端末上で収集し、ダッシュボードの表示、ローカル分析、AI アシスタントへのコンテキスト提供に使用します。

1. **端末のハードウェア情報**：CPU のモデルと周波数、メモリの容量と種類、GPU のモデルと VRAM、ディスクのモデルと容量、ディスプレイの仕様、ネットワークアダプターの情報、システムのモデルと製造元。詳細は [データ処理と保存](/ja/digitallab/privacy/data-storage) を参照。
2. **システムのパフォーマンスデータ**：CPU 使用率、メモリ使用率、ディスク使用率、ネットワーク速度、プロセス一覧（PID、名前、CPU とメモリの使用量）。詳細は [データ処理と保存](/ja/digitallab/privacy/data-storage) を参照。
3. **NAS デバイスのデータ**：ユーザーが設定した NAS デバイスの CPU、メモリ、ディスク、Docker コンテナの状態（SSH 接続で収集し、データは端末上に保存）。詳細は [データ処理と保存](/ja/digitallab/privacy/data-storage) を参照。
4. **AI の対話履歴**：ユーザーと AI アシスタントの対話内容（AI 機能を使用した場合にのみ生成）。詳細は [AI データフロー](/ja/digitallab/privacy/ai-data-flow) を参照。
5. **AI メモリ（オプション、既定はオフ）**：設定でメモリを有効にした場合に限り、対話で明示的に述べ、長期的に記憶する価値がある好みが端末上に永続保存されます。詳細は [AI データフロー](/ja/digitallab/privacy/ai-data-flow) を参照。
6. **AI リクエストのコンテキスト（AI 機能を使用した場合にのみ生成）**：選択した AI サービス提供者へ送信するリクエストには、静的プロンプト、メモリ内容（有効時）、リアルタイムのシステム状態の要約、および最近の対話内容が含まれます。API Key は HTTP リクエストヘッダーに認証用としてのみ配置され、モデルが参照可能なリクエスト内容には含まれません。詳細は [AI データフロー](/ja/digitallab/privacy/ai-data-flow) を参照。

## 能動的に収集しない情報

DigitalLab は以下を能動的に収集しません。

- 個人を特定できる情報（氏名、メールアドレス、電話番号）
- ブラウザの履歴、Cookie、パスワード
- ファイルの内容（ディスク使用率の統計のみで、ファイルの内容は走査しません）
- スクリーンショットやキーボード入力の記録
- 位置情報
- 連絡先やアドレス帳

ただし、ユーザー自身が入力した情報は別です。対話で述べた個人情報、設定で入力した呼称やデバイス名は、「収集する情報」および [データの保存場所](/ja/digitallab/privacy/data-storage#データの保存場所) に従って端末上に保存されます。クラウドモデルを使用する場合、対話内容と AI リクエストのコンテキストは選択したサービス提供者へ送信されます。クラウドサービス提供者へ送信したくない機密情報は、対話や設定に入力しないでください。

## AI エンドポイントの通信ポリシー

AI リクエスト（Ollama および OpenAI 互換 API）を送信する前に、アプリは設定したサービスアドレスをチェックします。

| 対象アドレス | 許可 | 説明 |
| --- | --- | --- |
| リモート HTTPS | 許可 | 既定の TLS 証明書検証を使用します。アプリは検証を無効にするスイッチを提供しません |
| loopback HTTP（`127.0.0.0/8`、`::1`、`localhost`） | 許可 | `localhost` はすべて回送アドレスに解決され、システムプロキシをバイパスします |
| プライベートネットワークまたは Tailscale の HTTP | 正確な許可後のみ許可 | 設定項目 `ai.allow_insecure_http` に IP リテラル `ip[:port]` を登録する必要があります |
| ドメイン形式の HTTP | 拒否 | 許可の例外はありません |
| パブリック IP の HTTP | 拒否 | 許可の例外はありません |
| link-local またはクラウドメタデータアドレスの HTTP | 拒否 | 許可の例外はありません |

リクエストは HTTP リダイレクトに追随しません。ネットワーク範囲、`ai.ca_bundle`、および許可方式の詳細は [機密情報の取り扱い](/ja/digitallab/privacy/sensitive-information#ai-エンドポイントの通信ポリシー) を参照してください。

## 第三者サービスについて

DigitalLab は、ユーザーが自ら設定した場合に限り、以下の第三者サービスへ接続することがあります。

1. **Ollama（ローカルモデル）**：AI アシスタント機能で、既定で本機の `localhost:11434` に接続し、データは端末外へ出ません。アドレスを他のホストに変更した場合、リクエストは当該ホストへ送信され、上記の通信ポリシーが適用されます。
2. **クラウドモデル（OpenAI 互換 API、例：DeepSeek）**：AI アシスタント機能。送信内容は、対話内容、プロンプトテンプレート、リアルタイムのシステム状態の要約（CPU/メモリ/ディスク使用率、ハードウェアの型番と容量、NAS の名前と負荷）、（AI メモリ有効時の）長期メモリの内容です。API Key は `Authorization: Bearer` リクエストヘッダーとして認証用にのみ使用されます。この部分のデータは選択したサービス提供者が処理し、そのプライバシーポリシーに従います。
3. **NAS デバイス**：入力したホストアドレスとポートへ SSH で接続します。ネットワークパスはそのアドレスとユーザーのネットワーク環境（ローカルネットワーク、VPN、Tailscale など）に依存し、アプリはローカルネットワークデバイスへの接続に限定しません。

上記の接続は、ユーザーが設定または能動的に使用した後にのみ発生し、既定ではどの遠隔サービスにも接続しません。

## ポリシーの変更

本プライバシーポリシーを更新する場合は、PRIVACY.md 上部の「最終更新」日付を合わせて変更し、アプリのバージョンとともに公開します。データの取り扱い方法に関わる重大な変更は、アプリ内またはプロジェクトリポジトリのリリースノートで通知します。更新後のバージョンを引き続き使用することにより、改訂後のポリシーに同意したものとみなされます。
