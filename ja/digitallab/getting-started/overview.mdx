DigitalLab は**個人向けデジタルラボプラットフォーム**で、個人のデバイス管理、データ感知、AI 拡張を実現するデスクトップアプリケーションです。ローカル優先、モジュール式、拡張可能であり、あなたのパソコンをプログラミング可能で感知可能、対話可能なデジタルワークスペースに変えます。

<Info>
  **配布チャネルの変更**: DigitalLab v1.6.0 は GitHub Releases で単体インストーラーを提供する最後のバージョンです。v1.6.1 以降、正式版は [Microsoft Store](https://apps.microsoft.com/detail/9n0rtlx1bcp5) でのみ配布され、GitHub は引き続きソースコード、ドキュメント、コラボレーションの場として運用されます。
</Info>

## コア設計原則

DigitalLab の設計は、以下の4つの原則に基づいています。

- **すべてのデータは system_state に入り、すべての UI は system_state のみを消費する**: 単一のデータソースにより、フロントエンドとバックエンドを分離
- **ローカル優先、モジュール式、拡張可能**: コア機能にネットワークは不要で、パネルは必要に応じて読み込み
- **Electron コア通信は HTTP に依存しない**: JSON Lines IPC プロトコルを採用し、ネットワークオーバーヘッドはゼロ。同時にオプションの Web Dashboard サービスも提供
- **Privacy First**: デバイスデータは既定でローカルに保存され、機密設定はユーザーディレクトリに保存。AI および NAS の認証情報は、現在の Windows ユーザーの DPAPI 暗号文として保存され、リモート AI エンドポイントは HTTPS を要求します（詳しくは [機密情報の取り扱い](/ja/digitallab/privacy/sensitive-information) を参照）

## システムアーキテクチャ

DigitalLab は Electron + Python のハイブリッドアーキテクチャを採用しています。Electron メインプロセスがウィンドウ管理と IPC 通信を担当し、Python サブプロセスが監視収集、ハードウェア検出、NAS SSH、AI 機能を担当します。両者は stdin/stdout 上の JSON Lines プロトコルで通信します。詳細なアーキテクチャの説明は [システムアーキテクチャ概要](/ja/digitallab/architecture/overview) を参照してください。
