DigitalLab は5つのモジュール式パネルで構成され、各パネルが異なるデータ感知とインタラクションの役割を担っています。以下、パネルごとに機能詳細を示し、テスト段階の項目や v1.2.0 から v1.6.0 にかけて追加されたユーザーわかりやすい機能、および計画中の機能を記載します。

---

## ダッシュボード

[ダッシュボードと監視](/ja/digitallab/user-guide/dashboard) は、システム実行状態のリアルタイムビューを提供します。

- CPU、メモリ、ディスク、ネットワーク速度のリアルタイム監視
- ミニトレンドラインとヘルス状態ランプで一目で把握
- 性能履歴グラフ（24 時間の平均値とピーク値）
- プロセス一覧の表示
- NAS デバイスのステータスカード

---

## デバイスセンター

[デバイスセンター](/ja/digitallab/user-guide/device-center) は、本機ハードウェア情報の一覧を表示します。

- CPU モデル、コア数、スレッド数、周波数
- メモリ容量、種類、周波数、スロット情報
- GPU モデル、ビデオメモリ、温度、使用率
- ディスク モデル、容量、健全性、パーティション情報
- ディスプレイ解像度、リフレッシュレート
- ネットワークアダプターの状態
- システム情報（OS バージョン、稼働時間）

## SSH ターミナル

[NAS と SSH ターミナル](/ja/digitallab/user-guide/nas-ssh-terminal) は、リモートデバイスの管理能力を提供します。

- xterm.js ベースのターミナル。独立した「DigitalLab Terminal」ウィンドウで実行
- SSH を介して設定済みかつオンラインの NAS デバイスに接続
- 初回接続時はホスト指紋の照合と信頼が必要。未信頼のホストには認証情報が送信されません
- ターミナルオープン前にシステムネイティブ確認ダイアログが表示され、デバイスと接続先アドレスが表示されます
- CMD 風ダークテーマ

<Warning>
  SSH ターミナルは現在**テスト段階**です。初回アクセス時にポップアップで通知されます。SSH セッションは自動再接続に未対応です。ターミナルウィンドウを閉じるか接続が切断された場合、ターミナルパネルから再度オープンする必要があります。
</Warning>

## AI アシスタント

[AI アシスタント](/ja/digitallab/user-guide/ai-assistant) は、システムコンテキストに基づく対話機能を提供します。

- ストリーミング出力。Token の逐次レンダリング
- Ollama ローカルモデルまたは OpenAI 互換 API（DeepSeek など）に対応
- マルチターン対話。現在のシステム状態を対話コンテキストとして自動注入
- CPU、メモリ、ディスク、ハードウェア、NAS に関する質問に回答
- 中国語の文字化けは修正済み。中国語能力の高いモデル（`qwen2.5:7b-instruct-q4_K_M` など）の使用を推奨
- オプションの AI 長期メモリ（既定で無効）。ローカルの会話履歴とは独立
- リモート AI エンドポイントは HTTPS を要求。ローカル Ollama の loopback HTTP は例外

<Warning>
  AI アシスタントは現在**テスト段階**です。初回アクセス時にポップアップで通知されます。現在は対話モードであり、**Agent のツール呼び出し機能は含まれません**。AI アシスタント上部の「クイックデプロイ」は将来のアップデートで有効化される予定です。
</Warning>

## 設定パネル

[設定と環境設定](/ja/digitallab/user-guide/settings) は、アプリの設定を一元管理します。

- ログレベルの調整
- 監視しきい値の設定
- NAS デバイス管理と SSH ホストの信頼設定
- AI プロバイダーの切り替え。API Key は「設定済み」のステータスのみ表示
- ハードウェアアクセラレーションのオン/オフ
- ライト / ダークテーマの切り替え: ライトは Emerald デザインシステムに基づき、ターミナルはいずれのテーマでもダークのまま
- 統合されたフィードバックと報告窓口（メール / GitHub Issues）

## ウィンドウとトレイ

アプリレベルのウィンドウおよびシステムトレイの動作:

- ウィンドウサイズ 1100 x 750、最小 900 x 600
- シングルインスタンスロックで多重起動を防止
- 閉じるボタンでシステムトレイに最小化。アプリは終了しません
- トレイメニューに「メインウィンドウを表示」と「終了」の2項目
- ハードウェアアクセラレーションは既定で無効。仮想マシン環境との互換性のため。設定で切り替え可能
- Python クラッシュ時は自動再起動。最大3回。超過した場合はユーザーに通知

## バージョンの変遷（ユーザーに見える機能）

v1.2.0 以降の主なユーザーに見える追加および改善を示します。

### v1.6.0（2026-11-09）

- AI/NAS 認証情報を Windows ユーザースコープのセキュアストレージ（DPAPI）に保存。既存の平文認証情報は起動時に自動移行
- メモリ、レポート、スナップショットなどの実行データをユーザーデータディレクトリに変更。インストールディレクトリへの書き込みを廃止
- AI メモリディレクトリにシステムネイティブディレクトリ選択ダイアログを使用
- AI ストリーム応答に 1 行あたり、合計サイズ、思考チャネルごとの上限を追加
- ターミナル同時オープン時に SSH セッションは 1 つだけ作成。ターミナルウィンドウの構築または読み込み失敗時に、作成済み SSH セッションを閉じる
- ダッシュボードとターミナルの CSP でレンダリングプロセスからのネットワーク接続を禁止
- 「このアプリについて」ページのライセンス表記を ISC に統一
- README の Personal Digital Memory を v1.6.0 完了としてマーク

完全な一覧は [変更履歴](/ja/digitallab/project/changelog) を参照してください。v1.6.0 は GitHub で単体インストーラーを提供する最後のバージョンです。

### v1.5.0（2026-10-09）

- ターミナル接続保持: パネル切り替え時に再接続しない。ウィンドウ非表示時もセッションを維持（v1.6.0 以降、ターミナルは独立ウィンドウで実行）
- AI 会話履歴: ローカル保存。再起動後に復元。設定パネルで消去可能
- AI メモリの構造化: エントリに id、タグ、出典フィールドを追加
- ログストームの修正: 5 MB ローテーション、50 MB 超過時に直接削除
- コマンドチャネルをネットワーク待ちでブロックしないように変更（SSH 接続確立と連通性テストを非同期実行）
- ステータスブロードキャストの重複排除
- モックデバイスがターミナルタブ一覧に表示されなくなった

### v1.4.0（2026-09-21）

- インターフェース多言語対応: 簡体字中国語、英語、日本語。設定でいつでも切り替え可能
- 初回起動ガイド: 3 ステップで初期設定を完了（表示言語の選択、NAS デバイスの追加、接続確認）
- しきい値アラート通知: CPU、メモリ、またはディスクが設定しきい値を超過し続けた場合にシステム通知を表示。数値が戻るまで再通知しない
- AI アシスタントが選択した表示言語で回答
- AI エラーメッセージの改善。表示言語に合わせて表示

### v1.3.0（2026-09-18）

- 起動スプラッシュアニメーション: 六角形と波形の描線、ロゴマークの出現、セルフチェック項目の逐次点灯
- スプラッシュアニメーションのダーク/ライトテーマ対応
- 設定パネルに「スプラッシュアニメーション」のオン/オフを追加
- AI アシスタント上部に「クイックデプロイ」のプレースホルダーボタンを追加
- フォントのローカライズ（Orbitron、Inter、JetBrains Mono）
- アプリアイコンの再描画

### v1.2.0（2026-09-10）

- AI ローカルメモリ機能
- CLI コマンドパネルの簡略化
