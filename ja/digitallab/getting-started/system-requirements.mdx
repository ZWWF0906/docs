DigitalLab は現在、Windows デスクトッププラットフォーム向けに提供されています。以下は README に記載された DigitalLab の最低システム要件です。

## 最低構成

| 要件 | 最低構成 |
| --- | --- |
| オペレーティングシステム | Windows 10 以降 |
| プロセッサ | x64 アーキテクチャ、デュアルコア 1.5 GHz |
| メモリ | 4 GB |
| グラフィックス | Windows 10 対応のグラフィックス/ディスプレイドライバ: ハードウェアアクセラレーションは設定でオフにできます |
| ストレージ | 2 GB の空き容量 |

## 補足事項

- **Python や Node.js のインストールは不要**: すべての依存関係は配布パッケージに内包されているため、一般ユーザーが追加で実行環境をインストールする必要はありません。
- **特定の VRAM は不要**: DigitalLab 自体は特定の VRAM を要求しません。ローカルの Ollama モデルを使用する場合、VRAM とメモリの必要量は実行するモデルに依存します。
- **ハードウェアアクセラレーションはデフォルトで無効**: アプリケーションはデフォルトでハードウェアアクセラレーションを無効にしており、仮想マシン環境での互換性を高めています。**設定パネル**で再度有効にでき、変更後は再起動が必要です。
- **データディレクトリ**: 実行時のデータは現在のユーザーの `%APPDATA%\DigitalLab\` と `%APPDATA%\digital-lab\` に書き込まれます。インストールディレクトリにはプログラムファイルと `launchers.json` などの少量のローカルファイルのみが保持されます。詳細は [データ処理と保存](/ja/digitallab/privacy/data-storage) を参照してください。

## 開発者環境

ソースコードから DigitalLab を開発または独自にビルドするには、Node.js 18+ と Python 3.10+ が必要です。開発者環境の詳細な設定方法は [開発環境](/ja/digitallab/development/environment) を参照してください。

<Note>
  `requirements.txt` ファイルの先頭に記載された実行環境は Windows 7/8/10/11 x64 および Python 3.7+ ですが、README では「Windows 10+ / Python 3.10+」となっています。**README のシステム要件を優先してください**。README は現在のバージョンの公式システム要件説明です。
</Note>
