DigitalLab の機能の進化は、完了したマイルストーンと計画中だがまだリリースされていない方向性に分かれています。最初の 2 セクションの内容はリポジトリの README の Roadmap 章節からのものであり、追加の約束やスケジュールは含まれていません。

## 完了したマイルストーン

| マイルストーン | バージョン |
| --- | --- |
| システムリアルタイム監視 | v1.0.0 |
| ハードウェア情報センター | v1.0.0 |
| NAS SSH 管理 | v1.0.0 |
| AI Assistant | v1.0.0 |
| Electron + Python アーキテクチャ | v1.0.0 |
| ライトテーマとテーマ切り替え | v1.1.0 |
| フィードバックと報告の窓口 | v1.1.0 |
| Personal Digital Memory | v1.6.0 |

## 計画中の方向性

<Warning>
  以下の項目はまだリリースされておらず、ソースドキュメントにもリリース時期は示されていません。これらは現在の製品方向性を反映しているに過ぎず、機能の約束を構成するものではありません。
</Warning>

- Agent 自動化機能
- プラグインシステム
- より多くの NAS プラットフォーム対応
- データ分析とタイムラインシステム

## その他のリリース済み機能（変更履歴から）

README の Roadmap には以下の機能が個別に記載されていません。これらは変更履歴から整理されたユーザーに見える追加項目です。

| 機能 | 開始バージョン | 説明 |
| --- | --- | --- |
| AI ローカルメモリ | v1.2.0 | オプション機能、既定はオフ |
| 起動スプラッシュアニメーション | v1.3.0 | 六角形のストローク描画とセルフチェックの点灯、深浅両テーマ対応 |
| フォントのローカル化 | v1.3.0 | Orbitron、Inter、JetBrains Mono |
| インターフェースの多言語対応（簡中/英語/日本語） | v1.4.0 | 設定からいつでも切り替え可能 |
| 初回起動ガイド | v1.4.0 | 3 ステップで初期設定を完了 |
| しきい値アラート通知 | v1.4.0 | CPU・メモリ・ディスクが持続的にしきい値を超えた際にシステム通知を発行 |
| AI 会話履歴 | v1.5.0 | ローカル保存、再起動後に復元 |
| AI メモリの構造化 | v1.5.0 | 項目に id・タグ・取得元フィールドを追加 |
| ターミナル接続の保持 | v1.5.0 | パネル切り替えとウィンドウ非表示でもセッションを維持 |
| メモリとパスのセキュリティ強化 | v1.6.0 | メモリの重複排除と会話履歴の並行書き込みでデータ消失を防止、履歴書き込みをアトミック化。メモリディレクトリと CA Bundle が UNC・デバイスパス・パス走査・シンボリックリンクを拒否。実行データをユーザーデータディレクトリに移動 |
| 資格情報の安全な保存 | v1.6.0 | AI/NAS の資格情報を Windows のユーザー範囲の安全な保存領域で保護、旧平文を自動移行して削除 |
| ローカルメモリの検索 | v1.6.0 | 純ローカルのキーワード + 構造化メタデータの関連性ソート（フェーズ 1、ベクトルライブラリは導入しない） |

詳細な変更記録は [変更履歴](/ja/digitallab/project/changelog) をご覧ください。
