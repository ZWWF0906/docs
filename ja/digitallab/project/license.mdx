## サードパーティフォントのライセンス

DigitalLab には以下のフォントが同梱されており、それぞれ独自のライセンスファイルが付属しています。

- **Inter**（`build/fonts/OFL-Inter.txt`）
- **JetBrains Mono**（`build/fonts/OFL-JetBrainsMono.txt`）
- **Orbitron**（`build/fonts/OFL-Orbitron.txt`）

上記フォントファイルのヘッダーには、SIL Open Font License, Version 1.1 が適用されていることが記載されています。具体的な条項については、リポジトリ内の対応するファイルを直接ご確認ください。
