DigitalLab はコミュニティからの参加を歓迎します。Issues または Pull Requests を通じて改善を提出できます。

## フィードバックと報告チャンネル

| チャンネル | アドレス / 連絡先 |
| --- | --- |
| GitHub Issues | [https://github.com/ZWWF0906/Digital-Lab/issues](https://github.com/ZWWF0906/Digital-Lab/issues) |
| メール | [ZWWF0906@outlook.com](mailto:ZWWF0906@outlook.com) |

Issue を提出する際は、できる限り以下の情報を記載してください：

- オペレーティングシステムのバージョン
- DigitalLab のバージョン番号
- 再現手順
- 期待される動作と実際の動作
- 異常がある場合は、`%APPDATA%\digital-lab\digital-lab.log` の該当する部分を添付することもできます

## Pull Request

コードの変更を提出する場合は、まずリポジトリをフォークし、ブランチ上で変更を加えてから Pull Request を通じて提出してください。提出前に、変更内容がローカルの開発環境で正常に動作することを確認してください。

## 多言語ドキュメント

リポジトリには、すでに複数言語版のユーザー向けドキュメントが存在します：

- `README.md` / `README.en-US.md` / `README.ja-JP.md`
- `CHANGELOG.zh-CN.md` / `CHANGELOG.md` / `CHANGELOG.ja-JP.md`
- `PRIVACY.md`（簡体字中国語、英語、日本語の 3 言語を含む）

変更内容がユーザーに見えるテキストやドキュメントに影響する場合は、他の言語バージョンの更新も同時に検討することをおすすめします。これにより、情報の整合性を保つことができます。

</Note>
