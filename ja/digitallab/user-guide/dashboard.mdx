ダッシュボードは DigitalLab のデフォルトホーム画面であり、ローカルマシンと NAS デバイスのリアルタイムな稼働状態を一括表示します。アプリを開くと、すべての主要指標を **ダッシュボード** パネルで確認できます。

## リアルタイム監視カード

上部には 5 枚のリアルタイム指標カードが表示されます。**CPU**、**メモリ**、**ディスク**、**ネットワーク**、**GPU** の各カードには、現在の数値、ミニトレンド線、ヘルスステータスランプ、プログレスバーが含まれます。

- **ステータスランプの色**:
  - 緑: 指標は正常
  - 琥珀色: 指標が第1しきい値を超過
  - 赤: 指標が第2しきい値を超過
- **ミニトレンド線**: 直近 60 サンプリングポイントの変化トレンドを表示し、指標の動向を素早く判断できます。
- **追加情報**: CPU カードには現在の周波数、メモリカードには総容量、ディスクカードには総容量、GPU カードには GPU モデルが表示されます。

## NAS デバイスの状態カード

**設定パネル** で NAS デバイスを追加している場合、ダッシュボードには対応する NAS 状態カードが表示されます。各カードには、そのデバイスの CPU、メモリ、ディスク使用率、温度、稼働時間が表示されます。

- オンラインのデバイスは通常通りデータを表示します
- オフラインのデバイスは半透明で表示され、再試行ボタンが付きます
- NAS が未設定の場合、設定からデバイスを追加するよう促すメッセージが表示されます

## ローカル詳細領域

### ハードウェア情報

**ハードウェア情報** のタイトルをクリックすると、領域の展開と折りたたみができます。展開すると 5 枚のハードウェアカードが表示されます。

- **プロセッサ**: モデル、コア数、スレッド数、現在の周波数
- **グラフィックスカード**: モデル、VRAM 容量、VRAM タイプ
- **メモリ**: 総容量、タイプ、周波数
- **ドライブ**: 総容量、モデル、タイプ
- **システム**: OS バージョン、ディストリビューション情報

NAS デバイスがオンラインでハードウェア情報が収集されている場合、そのハードウェアカードも同領域に表示されます。

### プロセス Top 15

**プロセス Top 15** のタイトルをクリックすると、プロセス一覧の展開と折りたたみができます。一覧には以下の列が含まれます。

| 列名 | 説明 |
| --- | --- |
| 名前 | プロセス名 |
| CPU % | CPU 使用率 |
| メモリ % | メモリ使用率 |
| RSS | 実際に使用しているメモリサイズ |
| PID | プロセス ID |

## しきい値アラート通知

v1.4.0 から、CPU、メモリ、ディスクが設定されたしきい値を超え続けた場合、デスクトップ通知が表示されます。数値がしきい値以下に戻るまで、繰り返し通知は行われません。

デフォルトのしきい値は以下の通りです。

| 指標 | デフォルトしきい値 |
| --- | --- |
| CPU アラート | 80% |
| メモリアラート | 85% |
| ディスクアラート | 90% |

これらのしきい値は、**設定パネル** の **収集設定** タブで調整できます。

## 性能履歴

README によると、ダッシュボードは 24 時間以内の平均値と最大値を示す性能履歴グラフをサポートしています。性能データはバックエンドによってローカルに収集・保存され、保存場所と形式については [データ処理と保存](/ja/digitallab/privacy/data-storage) を参照してください。

<Note>
  現在のリポジトリ main ブランチ（v1.6.0）のソースコードでは、バックエンドの `main.py` は引き続き `get_history` コマンド（引数は時間数）を提供していますが、プリロードスクリプト `preload.js` は `getHistory` インターフェースを公開しなくなっており、ダッシュボードパネルのコードからも履歴グラフを呼び出している箇所は見つかりませんでした。README で説明されている 24 時間履歴グラフが現在の UI でどのように表示されるかは、メンテナーに確認する必要があります。
</Note>
