デバイスセンターは DigitalLab のデバイス状態集約パネルであり、ローカルマシンと設定済みの NAS デバイスのハードウェア情報、リソース使用状況、プロセス一覧、Docker コンテナの状態を表示します。

## デバイス一覧

**デバイスセンター** を開くと、まずデバイス一覧カードが表示されます。

- **ローカルホスト**: DigitalLab を実行しているコンピューターを表し、常に表示されます
- **NAS デバイス**: 設定済みでオンラインの各 NAS に対して 1 枚のカードが表示されます

各カードには、デバイスの CPU、メモリ、ディスク使用率が表示されます。オフラインの NAS デバイスは半透明で表示され、詳細の展開はできません。

**ローカルホスト** カードをクリックすると、**ダッシュボード** パネルに直接ジャンプします。オンラインの NAS カードをクリックすると、そのデバイスの詳細ビューが展開されます。

## NAS デバイスの詳細

NAS デバイスの詳細を展開すると、以下の内容が表示されます。

### リソース指標カード

CPU、メモリ、ディスクの使用率が詳細に表示され、ステータスランプとプログレスバーが付きます。

### NAS の追加情報

デバイスの温度、稼働時間、ホストアドレスが表示されます。

### プロセス一覧

NAS 上で CPU またはメモリを多く使用しているプロセスが表示されます。内容は以下の通りです。

| 列名 | 説明 |
| --- | --- |
| PID | プロセス ID |
| 名前 | プロセス名 |
| CPU % | CPU 使用率 |
| メモリ % | メモリ使用率 |
| コマンド | 起動コマンドライン（マウスを重ねると全文が表示されます） |

### Docker コンテナ

NAS 上で Docker が実行されている場合、デバイスセンターにはコンテナ名、イメージ、実行状態が一覧表示されます。一覧の下部には、実行中のコンテナ数とコンテナ総数のサマリーが表示されます。

## ローカルのハードウェア情報

デバイスセンターで表示されるハードウェアデータは、DigitalLab のハードウェア収集モジュールから取得します。起動速度を向上させるため、ハードウェア情報は `%APPDATA%\DigitalLab\logs\cache\hardware.json` にキャッシュされ、起動のたびに完全な情報を再収集することを防ぎます。

データ保存の詳細については、[データ処理と保存](/ja/digitallab/privacy/data-storage) を参照してください。

## オプション依存関係とハードウェア精度

DigitalLab のコアとなるハードウェア情報収集は、`psutil` などの基本ライブラリに基づいており、ほとんどの日常使用を満たしています。ソースコード開発と Python バックエンドを手動で実行するシーンでは、以下のオプション依存関係をインストールすることで、より正確なハードウェアデータを取得できます。

- `nvidia-ml-py`: より正確な NVIDIA GPU の温度と使用率（`pynvml` に対応）
- `py-cpuinfo`: クロスプラットフォームでの CPU モデルの正確な識別
- `pyamdgpuinfo`: AMD GPU 情報の収集

<Note>
  リポジトリのソースコードの `backend.spec` によると、パッケージング構成は `pynvml` を `hiddenimports` に追加しています。上記のオプション依存関係は、ソースコード開発環境での精度向上にのみ使用され、パッケージング後のアプリには追加で含まれていない未リストの依存関係は含まれません。
</Note>

これらの依存関係を開発環境で設定する必要がある場合は、[開発環境](/ja/digitallab/development/environment) ページを参照してください。
