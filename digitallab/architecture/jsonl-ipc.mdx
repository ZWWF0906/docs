DigitalLab 的核心通信采用 JSON Lines（JSONL）协议：每一行是一个完整的 JSON 对象，通过 UTF-8 编码在 `stdin/stdout` 上单向传输。Electron 主进程向 Python 子进程的 `stdin` 发送命令，Python 向 `stdout` 返回响应、事件与状态帧。

## 消息帧格式

### 请求帧（主进程 → Python）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `cmd` | `string` | 命令名称 |
| `requestId` | `string` | 由 `crypto.randomUUID()` 生成，用于匹配响应 |
| 其他字段 | 视命令而定 | 如 `hours`、`messages`、`provider`、`session_id` 等 |

### 响应帧（Python → 主进程）

命令处理完成后，Python 输出一行 JSON 并附带：

- `__cmd_response__: true` 标记
- `requestId` 回显请求中的 ID

若出错，响应包含 `error` 字段。常见场景：

- 命令不在白名单：返回 `error.code = "ipc.err.forbidden"`。
- 参数校验失败：返回 `error.code = "ipc.err.invalidParams"`。
- 命令处理器抛异常：返回 `"handler error: ..."`。
- stdin 行无法解析为 JSON：返回 `"invalid JSON"`。

### 超时

主进程 `sendToPython()` 设置 10 秒超时；超时后从 `pendingRequests` 中删除该请求并返回拒绝 Promise。

## 流式与异步事件

部分操作不通过 `__cmd_response__` 返回，而是以独立事件帧推送：

### AI 流式事件

- `type: "ai_token"`：逐字 token，带 `requestId` 与 `data.token`。
- `type: "ai_done"`：流结束，带完整 `text`、`memory`、`error` 与 `requestId`。

### 异步连接结果（v1.5.0+）

- `type: "terminal_connect_result"`：SSH 建链结果，含 `ok`、`session_id` 或 `error`。
- `type: "nas_test_result"`：NAS 连通性测试结果，含 `ok` 与错误信息。

### 终端输出

终端会话的输出帧不通过命令响应，而是直接推送：

```json
{"session_id": "a1b2c3d4", "data": "ls\r\nfile.txt\r\n"}
```

## 状态广播

Python 主循环每秒调用 `_format_state()` 构建状态帧并输出到 stdout。若当前帧字符串与上一帧完全相同，则跳过发送，但每 5 秒至少发送一次作为心跳：

```python
if frame != _last_frame or (now - _last_frame_ts) >= _HEARTBEAT_SECONDS:
    _safe_print(frame, flush=True)
    _last_frame = frame
    _last_frame_ts = now
```

<Note>
  上述状态广播去重行为来自 `main.py` 中 1.5.1 的主循环实现。
</Note>

状态帧包含以下顶层键：

- `monitor`：CPU、内存、磁盘、网速、进程列表（最多 15 条）。
- `hardware`：CPU、GPU、内存、磁盘、系统信息摘要。
- `nas`：各 NAS 设备的在线状态与负载。
- `alerts`：最近 5 条告警记录（含递增 `seq`）。

主进程收到状态帧后，通过 `mainWindow.webContents.send('state-update', data)` 广播给渲染进程。告警部分按 `seq` 去重，只弹出未通知过的新告警。

### stdout 锁

Python 后端使用 `_stdout_lock = threading.Lock()` 保护 `_safe_print`，防止主循环的状态推送与命令响应/流式事件在 stdout 上交织，导致 JSON 解析失败。

## 示例 JSON Lines

**请求**：

```json
{"cmd": "get_hardware", "requestId": "a1b2-c3d4-e5f6-7890"}
```

**响应**：

```json
{"hardware": {"cpu": {"model": "Intel Core i7", "cores": 8, "threads": 16}, "gpu": {"name": "RTX 3060", "vram_gb": 12}}, "__cmd_response__": true, "requestId": "a1b2-c3d4-e5f6-7890"}
```

**AI token 流**：

```json
{"type": "ai_token", "requestId": "b2c3-d4e5-f6g7-8901", "data": {"token": "你好", "kind": "content"}}
```

**状态帧（节选）**：

```json
{"monitor": {"cpu": 8.2, "memory": 42.1, "disk": 55.3, "network_speed": 12.5, "processes": [...]}, "hardware": {"cpu": {"model": "Intel Core i7", "cores": 8, "threads": 16}, "gpu": {"name": "RTX 3060", "vram_gb": 12}}, "nas": {"NAS-01": {"online": true, "cpu": 15.0, "memory": 32.0, "disk": 40.0}}, "alerts": []}
```
