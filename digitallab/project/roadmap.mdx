DigitalLab 的功能演进分为已完成的里程碑和计划中但尚未发布的方向。前两节内容均来自仓库 README 中的 Roadmap 章节，未添加额外的承诺或时间排期。

## 已完成的里程碑

| 里程碑 | 版本 |
| --- | --- |
| 系统实时监控 | v1.0.0 |
| 硬件信息中心 | v1.0.0 |
| NAS SSH 管理 | v1.0.0 |
| AI Assistant | v1.0.0 |
| Electron + Python 架构 | v1.0.0 |
| 浅色主题与主题切换 | v1.1.0 |
| 问题反馈与举报入口 | v1.1.0 |

## 计划中的方向

<Warning>

- Agent 自动化能力

- 更多 NAS 平台支持

- 数据分析与时间线系统
