## 第三方字体授权

DigitalLab 内置了以下字体，它们各自附带独立的许可文件：

- **Inter**（`build/fonts/OFL-Inter.txt`）
- **JetBrains Mono**（`build/fonts/OFL-JetBrainsMono.txt`）
- **Orbitron**（`build/fonts/OFL-Orbitron.txt`）

上述字体文件 header 均注明采用 SIL Open Font License, Version 1.1。如需了解具体条款，请直接查看仓库中的对应文件。
