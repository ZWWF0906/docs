DigitalLab 欢迎社区参与。你可以通过 Issues 或 Pull Requests 提交改进。

## 反馈与报告渠道

| 渠道 | 地址 / 联系方式 |
| --- | --- |
| GitHub Issues | [https://github.com/ZWWF0906/Digital-Lab/issues](https://github.com/ZWWF0906/Digital-Lab/issues) |
| 电子邮件 | [ZWWF0906@outlook.com](mailto:ZWWF0906@outlook.com) |

在提交 Issue 时，请尽量描述以下信息：

- 操作系统版本
- DigitalLab 版本号
- 复现步骤
- 预期行为与实际行为
- 如有异常，可附上 `%APPDATA%\digital-lab\digital-lab.log` 中的相关片段

## Pull Request

如果你希望提交代码改动，请先 Fork 仓库并基于你的分支进行修改，然后通过 Pull Request 提交。提交前请确保你的改动在本地开发环境中能够正常运行。

## 多语言文档

仓库中已存在多语言版本的用户面向文档：

- `README.md` / `README.en-US.md` / `README.ja-JP.md`
- `CHANGELOG.zh-CN.md` / `CHANGELOG.md` / `CHANGELOG.ja-JP.md`
- `PRIVACY.md`（含简体中文、英文、日语三个版本）

如果你的改动会影响用户可见的文案或文档，建议同时考虑是否需要更新其他语言版本，以保持信息一致。

<Note>
  本文档未规定编码规范、分支策略、CLA 或 CI 流程。请遵循仓库中已有代码的风格，并在必要时通过 Issue 与维护者沟通。
</Note>
