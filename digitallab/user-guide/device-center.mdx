设备中心是 DigitalLab 的设备状态聚合面板，展示本机和已配置 NAS 设备的硬件信息、资源使用概况、进程列表和 Docker 容器状态。

## 设备总览

打开**设备中心**后，首先看到的是设备总览卡片列表：

- **本地主机**：代表运行 DigitalLab 的电脑，始终显示
- **NAS 设备**：每个已配置且在线的 NAS 展示一张卡片

每张卡片显示设备的 CPU、内存和磁盘使用率。离线 NAS 设备显示为半透明，且无法点击展开详情。

点击**本地主机**卡片会直接跳转到**仪表盘**面板。点击在线 NAS 卡片可展开该设备的详细视图。

## NAS 设备详情

展开 NAS 设备详情后，你会看到以下内容：

### 资源指标卡

详细展示 CPU、内存和磁盘的使用率，带有状态灯和进度条。

### NAS 额外信息

显示设备温度、运行时间和主机地址。

### 进程列表

展示 NAS 上 CPU 或内存占用较高的进程，包含：

| 列名 | 说明 |
| --- | --- |
| PID | 进程 ID |
| 名称 | 进程名称 |
| CPU % | CPU 占用百分比 |
| 内存 % | 内存占用百分比 |
| 命令 | 启动命令行（鼠标悬停可查看完整内容） |

### Docker 容器

如果 NAS 上运行着 Docker，设备中心会列出容器名称、镜像和运行状态。列表底部显示运行中容器数与容器总数的汇总。

## 本机硬件信息

设备中心展示的硬件数据来自 DigitalLab 的硬件采集模块。为了提升启动速度，硬件信息会缓存到 `%APPDATA%\DigitalLab\logs\cache\hardware.json`，避免每次启动都重新采集完整信息。

关于数据存储的详细说明，请参考 [数据处理与存储](/digitallab/privacy/data-storage)。

## 可选依赖与硬件精度

DigitalLab 的核心硬件信息采集基于 `psutil` 等基础库，能满足大部分日常使用。在源码开发和手动运行 Python 后端的场景下，安装以下可选依赖可以获得更精确的硬件数据：

- `nvidia-ml-py`：更精确的 NVIDIA GPU 温度与利用率（对应 `pynvml`）
- `py-cpuinfo`：跨平台 CPU 型号精确识别
- `pyamdgpuinfo`：AMD GPU 信息采集

<Note>
  根据仓库源码中的 `backend.spec`，打包配置已将 `pynvml` 列入 `hiddenimports`。上述可选依赖仅在源码开发环境中提升精度，打包后的应用不额外包含未列出的依赖。
</Note>

如果你需要在开发环境中配置这些依赖，请参考 [开发环境](/digitallab/development/environment) 页面。
