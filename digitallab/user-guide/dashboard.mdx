仪表盘是 DigitalLab 的默认首页，集中展示本机和 NAS 设备的实时运行状态。打开应用后，你可以在**仪表盘**面板中查看所有核心指标。

## 实时监控卡片

顶部展示了五张实时指标卡：**CPU**、**内存**、**磁盘**、**网络** 和 **GPU**。每张卡片包含当前数值、迷你趋势线、健康状态灯和进度条。

- **状态灯颜色**：
  - 绿色：指标正常
  - 琥珀色：指标超过一级阈值
  - 红色：指标超过二级阈值
- **迷你趋势线**：显示最近 60 个采样点的变化趋势，帮助你快速判断指标走向。
- **附加信息**：CPU 卡显示当前频率，内存卡显示总容量，磁盘卡显示总容量，GPU 卡显示 GPU 型号。

## NAS 设备状态卡片

如果你在**设置面板**中添加了 NAS 设备，仪表盘会展示对应的 NAS 状态卡片。每张卡片显示该设备的 CPU、内存和磁盘使用率，以及温度和运行时间。

- 在线设备正常显示数据
- 离线设备会显示为半透明，并附带重试按钮
- 未配置 NAS 时，界面上会提示前往设置添加设备

## 本地详情区域

### 硬件信息

点击**硬件信息**标题可展开或折叠该区域。展开后展示五张硬件卡片：

- **处理器**：型号、核心数、线程数、当前频率
- **显卡**：型号、显存容量、显存类型
- **内存**：总容量、类型、频率
- **硬盘**：总容量、型号、类型
- **系统**：操作系统版本、发行版信息

如果 NAS 设备在线且已采集到硬件信息，其硬件卡片也会显示在该区域中。

### 进程 Top 15

点击**进程 Top 15**标题可展开或折叠进程列表。列表包含以下列：

| 列名 | 说明 |
| --- | --- |
| 名称 | 进程名称 |
| CPU % | CPU 占用百分比 |
| 内存 % | 内存占用百分比 |
| RSS | 实际使用内存大小 |
| PID | 进程 ID |

## 阈值告警通知

从 v1.4.0 开始，当 CPU、内存或磁盘持续超过设定阈值时，系统会弹出桌面通知。数值回落到阈值以下前不会重复提醒。

默认阈值如下：

| 指标 | 默认阈值 |
| --- | --- |
| CPU 告警 | 80% |
| 内存告警 | 85% |
| 磁盘告警 | 90% |

你可以在**设置面板**的**采集设置**分页中调整这些阈值。

## 性能历史

根据 README，仪表盘支持性能历史图表，展示 24 小时内的平均值与峰值。性能数据由后端在本地采集并保存，存储位置与格式见 [数据处理与存储](/digitallab/privacy/data-storage)。

<Note>
  当前仓库 main 分支（v1.6.0）源码中，后端 `main.py` 仍提供 `get_history` 命令（参数为小时数），但预加载脚本 `preload.js` 已不再暴露 `getHistory` 接口，仪表盘面板代码中也未找到调用该命令的历史图表。README 描述的 24 小时历史图表在当前界面中的实际呈现方式有待维护者确认。
</Note>
