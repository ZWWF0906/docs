AI 助手是 DigitalLab 的智能对话面板，支持本地 Ollama 模型和云端 OpenAI 兼容 API，能够基于实时系统状态回答硬件、性能和 NAS 相关问题。

<Warning>
  **AI 助手**目前处于**测试阶段**，首次进入面板时会弹出提示。当前仅支持对话模式，不包含 Agent 工具调用能力。
</Warning>

## 模型提供方切换

AI 助手支持两种提供方，可以在面板顶部切换：

- **Ollama 本地**：连接本机 `localhost:11434`，数据不离开本机
- **云端 API**：连接你配置的 OpenAI 兼容服务端点，如 DeepSeek

切换提供方后会自动保存到配置，下次启动保持上次的选择。修改提供方、服务地址或 API Key 时，应用会弹出系统原生确认框。

### 服务端点要求

- **远程端点必须使用 HTTPS**，并使用系统默认的 TLS 证书校验，应用不提供关闭校验的开关
- **本地 loopback 地址**（如 `http://localhost:11434`）可以使用 HTTP
- **私网或 Tailscale 地址的 HTTP**：仅当你在配置项 `ai.allow_insecure_http` 中以 IP 字面量精确登记 `ip[:port]` 后才允许；使用域名的 HTTP 地址、公网 IP 的 HTTP 地址会被拒绝。设置面板当前没有该项的入口
- **自定义 CA**：可通过配置项 `ai.ca_bundle` 指定 CA Bundle 文件；显式配置的文件缺失或不可读时请求会直接失败，不会退回系统信任
- 请求不跟随重定向

详见 [敏感信息处理](/digitallab/privacy/sensitive-information)。

## 流式对话

AI 助手采用**流式输出**，模型生成的内容会逐字（token-by-token）显示在对话框中，无需等待完整回复。从 v1.6.0 起，流式响应对单行长度、总大小和思考（reasoning）通道设有上限。

发送消息后，AI 的回答会自动注入当前系统状态作为上下文，包括：

- CPU、内存、磁盘实时使用率
- 本机硬件型号与容量
- 已配置 NAS 设备的在线状态和负载指标

你可以直接询问"我的 CPU 占用多少""NAS 内存还够用吗"等问题，AI 会基于实时数据作答。

## 推荐模型

如果使用本地 Ollama，推荐使用具备良好中文能力的模型：

- `qwen2.5:7b-instruct-q4_K_M`

## 界面语言

从 v1.4.0 开始，AI 助手会按你选择的界面语言作答。在**设置面板**中切换简体中文、英文或日文后，AI 的回答会跟随该语言。

## 对话历史

从 v1.5.0 开始，对话历史默认开启保存，存储在 `%APPDATA%\DigitalLab\memory\chat_history.jsonl` 中：

- 重启应用后自动恢复上次的对话
- 可以在**设置面板**中关闭保存、调整保留条数上限或一键清空

<Note>
  关闭"保存对话历史"只会停止写入新记录，不会删除已有文件。当前发送的消息仍会继续随请求发送给 AI 提供方。
</Note>

## AI 记忆

AI 记忆是保存在本机的长期记忆，**默认关闭**。开启后，AI 会记住你在对话中明确表达的长期偏好（如称呼、设备名、使用习惯），并在后续对话中引用。

- **存储位置**：默认 `%APPDATA%\DigitalLab\memory\ai_memory.jsonl`，可在设置中通过原生目录选择器更换目录
- **条目结构**：每条记忆包含内容、时间、类别、标签与来源等字段；发送给模型的只有记忆内容本身，标识、类别、标签与来源字段不随请求发送
- **注入方式**：开启时，最近若干条记忆会随请求注入；使用云端模型时，这些记忆内容会发送给该服务商
- **关闭后**：不再写入新记忆，也不再读取或注入，但已有文件仍保留在本机

你可以在**设置面板**中查看记忆条目、逐条删除、清空全部或清理重复条目（同一内容保留最早一条）。

<Note>
  **版本演进**：v1.2.0 引入本地记忆，v1.5.0 为条目增加 id、标签与来源字段，README 的 Roadmap 将 Personal Digital Memory 标记为 v1.6.0 完成。当前实现为本地 JSONL 存储与关键词检索，不使用向量数据库。
</Note>

<Info>
  AI 记忆与对话历史是两个相互独立的功能：关闭其中一个不会关闭另一个，也不会停止 AI 请求。
</Info>

## 快速部署按钮

AI 助手面板顶部有一个**快速部署**按钮，这是 v1.3.0 添加的占位功能。点击后仅会弹出提示"功能正在开发中，敬请期待"，该功能尚未实现。

## Agent 自动化能力

<Warning>
  **Agent 自动化能力**是路线图中的计划项目，当前版本**尚未实现**。AI 助手仅支持对话问答，不具备工具调用、自动执行命令或自动部署的能力。
</Warning>

仓库中的 `core/agent_tools.py` 是只读 Agent 工具的基础设施，当前未暴露给模型（`MODEL_EXPOSURE_ENABLED = False`），不代表 AI 助手已具备工具调用能力。

## 隐私说明

使用云端模型时，以下数据会随请求发送到你配置的 API 端点：

- 对话内容（最近 16 条）
- 静态提示词与实时系统状态摘要
- 已开启的 AI 记忆内容

API Key 仅作为 `Authorization` 请求头发送，不写入提示词或对话正文。NAS 主机地址与凭据、完整进程列表、日志内容不随请求发送。使用本地 Ollama 时，上述数据仅在本机处理。

关于 AI 数据流的详细说明，请参考 [AI 数据流](/digitallab/privacy/ai-data-flow)。
