DigitalLab 内置基于 xterm.js 的 SSH 终端，可以连接你配置的 NAS 设备，执行远程命令和管理操作。从 v1.6.0 起，终端在独立的 "DigitalLab Terminal" 窗口中运行，终端面板本身只负责列出可连接的设备。

<Warning>
  **SSH 终端**目前处于**测试阶段**，首次进入面板时会弹出提示。部分功能可能不够稳定，遇到问题欢迎通过问题反馈入口报告。
</Warning>

## 添加 NAS 设备

使用终端前，你需要先在**设置面板**的 **NAS 设备**分页中添加设备：

1. 打开**设置面板**
2. 切换到 **NAS 设备**分页
3. 点击 **\+ 添加设备**
4. 填写设备名称、主机地址、SSH 端口、用户名和密码
5. 保存配置

设备添加后会自动尝试连接。你也可以在编辑设备时点击**测试连接**按钮验证凭据是否正确。NAS 必须已开启 SSH 服务。

## 信任 SSH 主机

DigitalLab 在发送认证凭据之前会先校验 NAS 的 SSH 主机密钥。信任关系按 `主机:端口` 记录，修改主机地址或端口会被视为一台新的主机。

<Steps>
  <Step title="查看指纹">
    首次连接一台未信任的主机时，连接会被拒绝，设置面板会显示该主机的 SHA256 指纹。
  </Step>
  <Step title="在 NAS 上独立核对">
    在 NAS 控制台执行以下命令，确认输出中的指纹与设置面板显示的一致：

    ```bash
    ssh-keygen -lf /etc/ssh/ssh_host_*_key.pub
    ```
  </Step>
  <Step title="确认信任">
    确认一致后，点击**我已核对，信任此主机**。指纹会保存到 `%APPDATA%\DigitalLab\ssh\ssh_trust.json`，然后重新测试连接。
  </Step>
</Steps>

- 未信任或指纹不一致的主机**不会收到认证凭据**
- 如果已信任主机的指纹发生变化，连接会被立即拒绝，直到你重新核对并信任
- 信任文件只保存主机公钥、算法、指纹与信任时间，不保存用户凭据或私钥

## 打开终端

<Steps>
  <Step title="进入终端面板">
    点击侧边栏的**终端**。面板会列出当前在线且非 Mock 的 NAS 设备。
  </Step>
  <Step title="选择设备">
    点击设备条目上的按钮。应用会弹出系统原生确认框"打开 SSH 终端？"，显示设备名称、目标 `主机:端口`，并提示未信任的主机不会收到认证凭据、终端将在独立窗口中运行。
  </Step>
  <Step title="在独立窗口中操作">
    确认后，终端在 "DigitalLab Terminal" 窗口中打开（默认 900 x 600，最小 600 x 400）。窗口状态栏显示 `Connected` 或 `Session closed`。
  </Step>
</Steps>

### 会话行为

- 已有终端窗口打开或正在打开时，再次打开会被拒绝
- 关闭终端窗口、窗口加载失败或渲染进程崩溃时，后端会关闭对应的 SSH 会话
- 后端为会话保留 256 KB 的输出缓冲，终端窗口连接到会话时会回放这段输出
- 单次输入最多 8192 个字符，并有频率限制
- 终端窗口的内容安全策略（CSP）禁止渲染进程发起网络连接

<Warning>
  SSH 会话**不支持自动重连**。窗口关闭、网络中断或后端重启导致会话结束后，需要回到终端面板重新打开终端。
</Warning>

### 终端主题

终端窗口在**深色主题**和**浅色主题**下均保持 CMD 风格的深色背景。

## 已知限制

- **仅支持基于 Linux 的 NAS**：通过 SSH 命令采集数据，其他平台的 NAS 暂不支持
- **不支持自动重连**：会话结束后需要手动重新打开
- **SSH 服务必须已开启**：请确保目标 NAS 的 SSH 服务已启动且凭据正确
- **首次连接需信任主机**：未完成指纹核对前无法完成认证

## 安全提醒

NAS 密码以 Windows DPAPI 当前用户范围密文（`dpapi:v1:`）保存在 `%APPDATA%\DigitalLab\user_config.json` 中，设置界面只显示"已配置"状态。主机地址、用户名等其他设备字段仍是可读的 JSON，该文件仍应按敏感文件保管，不要分享给他人。NAS 凭据不会随 AI 请求发送。

关于凭据存储的详细说明，请参考 [敏感信息处理](/digitallab/privacy/sensitive-information)。
