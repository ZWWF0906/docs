DigitalLab 内置基于 xterm.js 的 Web 终端，可以通过 SSH 连接到你配置的 NAS 设备，执行远程命令和管理操作。

<Warning>
  **SSH 终端**目前处于**测试阶段**，首次进入面板时会弹出提示。部分功能可能不够稳定，遇到问题欢迎通过问题反馈入口报告。
</Warning>

## 添加 NAS 设备

使用终端前，你需要先在**设置面板**的 **NAS 设备**分页中添加设备：

1. 打开**设置面板**
2. 切换到 **NAS 设备**分页
3. 点击\*\*+ 添加设备\*\*
4. 填写设备名称、主机地址、SSH 端口、用户名和密码
5. 保存配置

设备添加后会自动尝试连接。你也可以在编辑设备时点击**测试连接**按钮验证凭据是否正确。

## 终端使用

### 多会话标签

当有多台 NAS 设备在线时，终端面板顶部会显示设备标签页。点击标签可切换不同设备的会话。

### 连接保持

从 v1.5.0 开始，终端支持**连接保持**：

- 切换到其他面板（如仪表盘或 AI 助手）后，终端会话不会断开
- 隐藏应用窗口后，会话仍然保留
- 再次回到终端面板时，会自动恢复之前的会话内容

后端为每个会话保留 256KB 的输出环形缓冲，重新进入面板时会回放这段时间的输出。

<Warning>
  SSH 会话**不支持自动重连**。如果后端重启或网络中断导致会话丢失，回到终端面板时会自动重新建立连接。
</Warning>

### 终端主题

终端面板在**深色主题**和**浅色主题**下均保持 CMD 风格的深色背景，确保长时间操作的视觉舒适性。

## 已知限制

- **仅支持基于 Linux 的 NAS**：通过 SSH 命令采集数据，其他平台的 NAS 暂不支持
- **不支持自动重连**：会话丢失后需要手动重新连接
- **SSH 服务必须已开启**：请确保目标 NAS 的 SSH 服务已启动且凭据正确

## 安全提醒

NAS 设备的 SSH 用户名和密码以明文形式存储在 `%APPDATA%\DigitalLab\user_config.json` 中，未做加密处理。请妥善保管该文件，不要分享给他人。

关于凭据存储的详细说明，请参考 [敏感信息处理](/digitallab/privacy/sensitive-information)。
