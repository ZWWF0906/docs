DigitalLab 是一款**个人数字实验室平台**，面向个人设备管理、数据感知与 AI 扩展的桌面应用。本地优先、模块化、可扩展，将你的个人电脑转变为一个可编程、可感知、可对话的数字工作空间。

本文档以 GitHub 仓库 `main` 分支中的 **v1.6.0** 为基准编写，支持 **Windows 10 及更高版本**。

<Info>
  **发布渠道变更**：v1.6.0 是最后一个通过 GitHub Releases 提供独立安装包的版本。自 v1.6.1 起，正式版本仅通过 [Microsoft Store](https://apps.microsoft.com/detail/9n0rtlx1bcp5) 安装和更新；GitHub 继续作为源码、文档和协作平台。
</Info>

## 核心设计原则

DigitalLab 的设计围绕以下四项原则展开：

- **所有数据进入 system_state，所有 UI 只消费 system_state**：单一数据源，前端与后端解耦
- **本地优先，模块化，可扩展**：核心功能无需网络，面板按需加载
- **Electron 核心通信不依赖 HTTP**：采用 JSON Lines IPC 协议，零网络开销；同时提供可选 Web Dashboard 服务
- **Privacy First**：设备数据默认保存在本地，敏感配置存储于用户目录；AI 与 NAS 凭据以当前 Windows 用户的 DPAPI 密文保存，远程 AI 端点要求 HTTPS（详见 [敏感信息处理](/digitallab/privacy/sensitive-information)）

## 系统架构

DigitalLab 采用 Electron + Python 混合架构：Electron 主进程负责窗口管理与 IPC 通信，Python 子进程负责监控采集、硬件检测、NAS SSH 与 AI 功能。两者通过 stdin/stdout 上的 JSON Lines 协议通信。详细架构说明请参见 [系统架构概览](/digitallab/architecture/overview)。
