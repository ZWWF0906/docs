DigitalLab 由五个模块化面板组成，每个面板承担不同的数据感知与交互职责。以下按面板列出功能详情，并标注测试阶段项目、v1.2.0 至 v1.6.0 期间新增的用户可见特性，以及计划中的功能。

---

## 仪表盘

[仪表盘与监控](/digitallab/user-guide/dashboard) 提供系统运行状态的实时视图：

- CPU、内存、磁盘、网络速度的实时监控
- 迷你趋势线与健康状态灯，一目了然
- 性能历史图表（24 小时平均值与峰值）
- 进程列表展示
- NAS 设备状态卡片

---

## 设备中心

[设备中心](/digitallab/user-guide/device-center) 展示本机硬件信息全景：

- CPU 型号、核心数、线程数、频率
- 内存容量、类型、频率、插槽信息
- GPU 型号、显存、温度、利用率
- 磁盘型号、容量、健康度、分区信息
- 显示器分辨率、刷新率
- 网络适配器状态
- 系统信息（操作系统版本、运行时间）

## SSH 终端

[NAS 与 SSH 终端](/digitallab/user-guide/nas-ssh-terminal) 提供远程设备管理能力：

- 基于 xterm.js 的终端，在独立的 "DigitalLab Terminal" 窗口中运行
- 通过 SSH 连接已配置且在线的 NAS 设备
- 首次连接需核对并信任主机指纹，未信任的主机不会收到认证凭据
- 打开终端前弹出系统原生确认框，显示设备与目标地址
- CMD 风格深色主题

<Warning>
  SSH 终端目前处于**测试阶段**，首次进入时会弹窗提示。SSH 会话暂不支持自动重连：关闭终端窗口或连接断开后，需要从终端面板重新打开。
</Warning>

## AI 助手

[AI 助手](/digitallab/user-guide/ai-assistant) 提供基于系统上下文的对话能力：

- 流式输出，Token 逐字渲染
- 支持 Ollama 本地模型或 OpenAI 兼容 API（如 DeepSeek）
- 多轮对话，自动注入当前系统状态作为对话上下文
- 可回答 CPU、内存、磁盘、硬件、NAS 相关问题
- 已修复中文乱码，推荐使用具备良好中文能力的模型（如 `qwen2.5:7b-instruct-q4_K_M`）
- 可选的 AI 长期记忆（默认关闭），与本地对话历史相互独立
- 远程 AI 端点要求 HTTPS，本地 Ollama 的 loopback HTTP 除外

<Warning>
  AI 助手目前处于**测试阶段**，首次进入时会弹窗提示。当前为对话模式，**不包含 Agent 工具调用能力**。AI 助手顶部"快速部署"按钮为占位功能，点击后仅显示"功能正在开发中，敬请期待"的原生通知弹窗，实际功能尚未实现。
</Warning>

## 设置面板

[设置与偏好](/digitallab/user-guide/settings) 集中管理应用配置：

- 日志级别调整
- 监控阈值设定
- NAS 设备管理与 SSH 主机信任
- AI 提供商切换，API Key 只显示"已配置"状态
- 硬件加速开关
- 浅色 / 深色主题切换：浅色基于 Emerald 设计体系，终端在两种主题下均保持深色
- 统一的问题反馈与举报入口（邮件 / GitHub Issues）

---

## 窗口与托盘

应用层面的窗口与系统托盘行为：

- 窗口尺寸 1100 x 750，最小 900 x 600
- 单实例锁，防止多开
- 关闭按钮最小化到系统托盘，不退出应用
- 托盘菜单提供"显示主窗口"与"退出"两项
- 硬件加速默认关闭，以兼容虚拟机环境，可在设置中切换
- Python 崩溃自动重启，最多 3 次，超限后通知用户

## 版本演进（用户可见特性）

自 v1.2.0 起，以下为主要用户可见的新增与优化：

### v1.6.0（2026-11-09）

- AI/NAS 凭据使用 Windows 用户范围安全存储（DPAPI），已有明文凭据在启动时自动迁移
- 记忆、报告和快照等运行数据改存用户数据目录，不再写入安装目录
- AI 记忆目录使用系统原生目录选择器
- AI 流式响应增加单行、总大小和思考通道上限
- 同时打开终端只创建一个 SSH 会话；终端窗口构造或加载失败时会关闭已创建的 SSH 会话
- 仪表盘与终端的 CSP 禁止渲染进程发起网络连接
- "关于"页面的许可证标识统一为 ISC
- README 将 Personal Digital Memory 标记为 v1.6.0 完成

完整列表见 [更新日志](/digitallab/project/changelog)。v1.6.0 是最后一个提供 GitHub 独立安装包的版本。

### v1.5.0（2026-10-09）

- 终端连接保持：切换面板不再重连，隐藏窗口不丢失会话（v1.6.0 起终端改在独立窗口中运行）
- AI 对话历史：本地保存，重启后恢复，可在设置面板清空
- AI 记忆结构化：条目新增 id、标签与来源字段
- 日志风暴修复：5 MB 轮转，超过 50 MB 直接删除
- 命令通道不再被网络等待阻塞（SSH 建链与连通性测试改为异步执行）
- 状态广播去重
- Mock 设备不再出现在终端标签列表

### v1.4.0（2026-09-21）

- 界面多语言：简体中文、英文、日文，可在设置中随时切换
- 首次启动引导：三步完成初始设置（选择界面语言、添加 NAS 设备、检查连接）
- 阈值告警通知：CPU、内存或磁盘持续超过设定阈值时弹出系统通知，数值回落前不会重复提醒
- AI 助手按所选界面语言作答
- AI 出错提示更清晰，并跟随界面语言显示

### v1.3.0（2026-09-18）

- 启动开屏动画：六边形与波形描边、字标浮现、自检项逐项点亮
- 开屏动画适配深色与浅色主题
- 设置面板新增"开屏动画"开关
- AI 助手顶部新增"快速部署"占位按钮
- 字体本地化（Orbitron、Inter、JetBrains Mono）
- 应用图标重绘

### v1.2.0（2026-09-10）

- AI 本地记忆功能
- CLI 命令面精简
